Notation

Every chapter uses the symbols below: the letter says what kind of object a symbol is, the subscript says which variable it belongs to, and every symbol has a shape. Equations use x\vect{x}x in this documentation and Unicode, such as Σ_x|y, in code comments. Docstrings have not moved to these symbols yet, and the last section lists what they still use.

The convention that matters most is that an ensemble stacks its members as rows, X∈RNE×Dx\mat{X} \in \mathbb{R}^{N_\mathcal{E} \times D_x}X∈RNE​×Dx​, so axis 0 of every ensemble array is the ensemble axis. That matches the (N_e, N_x) shape of every filterax particles argument.
