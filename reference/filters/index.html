    Filters¶

    Sequential ensemble filters come in two layers:

    • Layer 1 — analysis steps (filterax.filters.*). A one-shot posterior update: forecast ensemble + observation + observation operator + noise covariance in, analysed ensemble out (AnalysisResult). All implement AbstractSequentialFilter and share the gaussx-backed ensemble-statistics primitives; they differ only in how the ensemble is updated.
    • Layer 2 — assimilation models (top-level filterax.*, same names). The full forecast → analyse → inflate loop: each composes an AbstractDynamics forecast (via eqx.filter_vmap), the matching L1 analysis step, and an optional AbstractInflator into a single assimilate() call over a sequence of observation windows, returning an AssimilationResult.

    So filterax.filters.ETKF is the one-shot analysis step, while filterax.ETKF is the loop built around it. Drop down to Layer 1 when the standard cycle does not fit (custom inflation schedules, pipekit cycling, differentiable training).

    ETKF analysis core

    ETKF, EnSRF, ESTKF and ETKF_Livings run gaussx.etkf_analysis. With fewer observations than members it takes a thin QR and an (N_y, N_y) symmetric eigendecomposition, and forms no (N_e, N_e) matrix; otherwise it takes one (N_e, N_e) eigendecomposition. Its derivative is taken in closed form, so it stays finite under jax.grad at the repeated eigenvalues of the transform (see Differentiable training).

    For the specialised deterministic variants (ESTKF, ETKF_Livings, EnSRF_Serial) see Advanced filters.

    Layer-1 analysis steps¶

    The everyday defaults: symmetric square-root ETKF, observation-space localized LETKF, serial-free EnSRF, and the perturbed-observations stochastic EnKF.

    Layer-1 sequential filters: the one-shot analysis steps, such as filters.ETKF().

    Re-exports the analysis steps of filterax._filters._sequential: StochasticEnKF, ETKF, EnSRF, LETKF, and the variants ETKF_Livings, with a mean-preserving random rotation, EnSRF_Serial, with one scalar update per observation, and ESTKF, in the error subspace. The parametric SquareRootKF and its SquareRootFilterResult live in filterax._filters._parametric and are re-exported here for convenience.

    ETKF ¶

    Bases: AbstractSequentialFilter

    Ensemble transform Kalman filter, a deterministic square-root analysis.

    Λ_w = (N_ℰ − 1) I + H̃ Σ_ε⁻¹ H̃ᵀ,   Σ_w = Λ_w⁻¹
w̄ = Σ_w H̃ Σ_ε⁻¹ r̄,   W = ((N_ℰ − 1) Σ_w)^½
x̄_t|t = x̄_t|t−1 + X̃ᵀ w̄,   X̃_t|t = W X̃

    The update works in the N_ℰ-dimensional space of the members, with the symmetric square root W, which keeps the analysis mean exact. It is gaussx.etkf_analysis, and the filter adds the map to observation space and the log-likelihood of r̄.

    With D_y < N_ℰ gaussx takes a thin QR of H̃ and a (D_y, D_y) eigendecomposition, at O(N_ℰ D_y² + N_ℰ D_y D_x), and forms no (N_ℰ, N_ℰ) matrix. Otherwise it eigendecomposes Λ_w at O(N_ℰ² D_y + N_ℰ³). Both routes have closed-form derivatives that stay finite at repeated eigenvalues, and Σ_ε⁻¹ goes through gaussx's solves, so a structured Σ_ε is never densified.

    Examples:

    Three members, both components observed:

    >>> import jax.numpy as jnp
>>> import lineax as lx
>>> from filterax.filters import ETKF
>>> particles = jnp.array([[0.0, 0.0], [1.0, 1.0], [2.0, 0.0]])
>>> obs_noise = lx.DiagonalLinearOperator(0.1 * jnp.ones(2))
>>> result = ETKF().analysis(
...     particles, jnp.array([1.0, 0.5]), lambda x: x, obs_noise
... )
>>> result.particles.shape
(3, 2)

    The analysis anomalies still sum to zero:

    >>> anomalies = result.particles - result.particles.mean(0)
>>> bool(jnp.allclose(anomalies.sum(0), 0.0, atol=1e-5))
True

    Local ensemble transform Kalman filter, with R-localization.

    Λ_w,i = (N_ℰ − 1) I + H̃ D_ρ,i^½ Σ_ε⁻¹ D_ρ,i^½ H̃ᵀ,   D_ρ,i = diag(ρ_i)
x̄_t|t,i = x̄_i + X̃_iᵀ w̄_i,   X̃_t|t,i = W_i X̃_i

    An independent ETKF analysis at each state component i, with its own weights w̄_i and transform W_i, from only the observations near it. Component i sits at s_i and observation k at s_k, at the distance d_ik = ‖s_i − s_k‖₂, and the observation enters with the weight

    ρ_ik = ρ(d_ik; ℓ) if d_ik ≤ ℓ, else 0

    from the taper ρ, the Gaspari-Cohn function by default. The cutoff at ℓ is explicit, because Gaspari-Cohn reaches out to 2 ℓ and would otherwise keep every observation with a nonzero taper. A weight divides the variance, ρ_ik / Σ_ε,kk.

    The weights at each i are gaussx.etkf_transform with obs_weights=ρ_i, mapped over the components with jax.vmap. The filter adds the distances, the taper and its cutoff, and applies the local weights to the global anomalies X̃ column by column. R-localization needs a diagonal Σ_ε (Hunt et al. 2007, §2), which is read with lineax.diagonal and never densified.

    and transform W_i, from only the observations near it. Component i sits at

    observation enters with the weight

        ρ_ik = ρ(d_ik; ℓ) if d_ik ≤ ℓ, else 0

    from the taper ρ, the Gaspari-Cohn function by default. The cutoff at ℓ is explicit,
    because Gaspari-Cohn reaches out to 2 ℓ and would otherwise keep every observation
    with a nonzero taper. A weight divides the variance, ρ_ik / Σ_ε,kk.

    def analysis(
        self,
        particles: Float[Array, "N_e N_x"],
        obs: Float[Array, " N_y"],
        obs_op: AbstractObsOperator | ObsCallable,
        obs_noise: lx.AbstractLinearOperator,
        *,
        state_coords: Float[Array, "N_x D"] | None = None,
        obs_coords: Float[Array, "N_y D"] | None = None,
        **_: Any,
    ) -> AnalysisResult:
        """LETKF analysis step.

        Algorithm:
            1. Check the coordinates and that Σ_ε is diagonal.
            2. Map the members to observation space and take the state anomalies X̃.
            3. At each component i, taper the observations by distance and form the
               local weights w̄_i and transform W_i.
            4. Apply them to the anomalies of component i and add its mean back.
            5. Score r̄ under 𝒩(0, Σ̂_y), unlocalized.

        Args:
            particles: Forecast ensemble x⁽ᵉ⁾_t|t−1, one row per member.
            obs: Observation y.
            obs_op: Observation operator h, applied to one state.
            obs_noise: Diagonal observation-error covariance Σ_ε.
            state_coords: Coordinates s_i of the state components, one row each.
            obs_coords: Coordinates s_k of the observations, one row each.

        Returns:
            The analysis ensemble and the log-likelihood log 𝒩(r̄; 0, Σ̂_y).

        Raises:
            ValueError: If N_ℰ < 2, if a coordinate array is missing, or if it does
                not have one row per state component or per observation.
            NotImplementedError: If ``obs_noise`` is not a
                `lineax.DiagonalLinearOperator`.
        """
        N_e, N_x = particles.shape
        check_ensemble_size(N_e)
        if state_coords is None or obs_coords is None:
            raise ValueError(
                "LETKF.analysis requires state_coords and obs_coords keyword "
                "arguments — pass them through the L2 model or the call site."
            )
        if state_coords.shape[0] != N_x:
            raise ValueError(
                "state_coords must have one row per state component; got "
                f"{state_coords.shape[0]} vs N_x={N_x}."
            )
        if obs_coords.shape[0] != obs.shape[0]:
            raise ValueError(
                "obs_coords must have one row per observation; got "
                f"{obs_coords.shape[0]} vs N_y={obs.shape[0]}."
            )
        if not isinstance(obs_noise, lx.DiagonalLinearOperator):
            raise NotImplementedError(
                "LETKF R-localization assumes diagonal observation noise "
                "(Hunt et al. 2007 §2). Pass a lineax.DiagonalLinearOperator "
                "or decorrelate observations beforehand."
            )

        # h⁽ᵉ⁾ = h(x⁽ᵉ⁾)
        obs_particles = _apply_obs_op(obs_op, particles)
        # x̃⁽ᵉ⁾ = x⁽ᵉ⁾ − x̄
        anomalies = ensemble_anomalies(particles)
        # x̄ = (1 / N_ℰ) ∑ₑ x⁽ᵉ⁾
        mean = ensemble_mean(particles)
        radius = self.radius

        def local_weights(
            state_point: Float[Array, " D"],
        ) -> tuple[Float[Array, " N_e"], Float[Array, "N_e N_e"]]:
            """Local weights w̄_i and transform W_i at one state component."""
            # s_k − s_i
            offsets = einx.subtract("y d, d -> y d", obs_coords, state_point)
            # (s_k − s_i)²
            squared_offsets = offsets * offsets
            # d_ik² = ‖s_i − s_k‖₂²
            squared_distances = einx.sum("y d -> y", squared_offsets)
            # d_ik = ‖s_i − s_k‖₂
            distances = jnp.sqrt(squared_distances)
            # the hard cutoff at ℓ, inside Gaspari-Cohn's support of 2 ℓ
            within = distances <= radius
            # ρ(d_ik; ℓ)
            tapered = self.taper_fn(distances, radius)
            # ρ_ik = ρ(d_ik; ℓ) if d_ik ≤ ℓ, else 0
            taper = jnp.where(within, tapered, 0.0)
            # w̄_i, W_i with Σ_ε⁻¹ ← D_ρ,i^½ Σ_ε⁻¹ D_ρ,i^½
            return gaussx.etkf_transform(
                obs_particles, obs, obs_noise, obs_weights=taper
            )

        # (w̄_i, W_i) for every component i
        mean_weights, transforms = jax.vmap(local_weights)(state_coords)

        # X̃_iᵀ w̄_i = ∑ₑ w̄_i,e x̃⁽ᵉ⁾_i
        mean_increment = einx.dot("x e, e x -> x", mean_weights, anomalies)
        # (W_i X̃_i)⁽ᵉ⁾ = ∑_e′ W_i,ee′ x̃⁽ᵉ′⁾_i
        analysis_anomalies = einx.dot(
            "x member other, other x -> member x", transforms, anomalies
        )

        # x̄_t|t,i = x̄_i + X̃_iᵀ w̄_i
        analysis_mean = einx.add("x, x -> x", mean, mean_increment)
        # x⁽ᵉ⁾_t|t = x̄_t|t + x̃⁽ᵉ⁾_t|t
        analysis_particles = einx.add(
            "x, e x -> e x", analysis_mean, analysis_anomalies
        )

        # log 𝒩(r̄; 0, Σ̂_y)
        log_likelihood = _innovation_log_likelihood(obs_particles, obs, obs_noise)
        return AnalysisResult(
            particles=analysis_particles, log_likelihood=log_likelihood
        )

    Ensemble square-root filter in batch form, which is the ETKF update.

    x̄_t|t = x̄_t|t−1 + G (y − h̄),   X̃_t|t = W X̃

    The mean moves by the gain, G r̄ = X̃ᵀ w̄, and the anomalies by a square root that gives the analysis covariance (I − G H) Σ̂_x of the linear-Gaussian case without perturbed observations. With the members as rows, the symmetric square root W of the ETKF is the one that is also mean-preserving (Tippett et al. 2003), so in batch form this class runs exactly the analysis of ETKF, through gaussx.etkf_analysis, and keeps the name for those who think of it this way.

    x_t = F x_t−1 + η_t,   η_t ~ 𝒩(0, Σ_η)

        self.inflator,

    class EncodedDynamics(AbstractDynamics, strict=True):
    """State-space dynamics run through the codec, as dynamics on the latent.

        z_t|t−1 = g_enc(f(g_dec(z_t−1|t−1)))

    exists: each step decodes, runs the dynamics f on the state, and encodes. Pass it

            decoder g_dec.

        With the identity codec it is the state-space dynamics:

        >>> import jax.numpy as jnp

        ...     def __call__(self, state, t0, t1):
        ...         return state + (t1 - t0)
        >>> dynamics = filterax.EncodedDynamics(
        ...     latent_map=filterax.identity_latent_map(1), inner=Shift()
        ... )
        >>> dynamics(jnp.array([1.0]), jnp.array(0.0), jnp.array(2.0)).tolist()
        [3.0]

    latent_map: Any
    inner: AbstractDynamics

    def __call__(
        self,
        state: Float[Array, " N_z"],
        t0: Float[Array, ""],
        t1: Float[Array, ""],
    ) -> Float[Array, " N_z"]:
        # x = g_dec(z_t−1|t−1)
