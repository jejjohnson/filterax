    Localization¶

    A small ensemble (N_e ≪ N_x) produces a rank-deficient sample covariance whose long-range entries are dominated by sampling noise: two physically unrelated variables will show spurious correlation of order 1/√N_e, and the filter will happily use it to spread observation increments across the whole domain. Localization suppresses these spurious long-range correlations by damping covariance entries as a function of physical distance.

    The standard mechanism is the Schur (element-wise) product P_loc = ρ ∘ P with a taper matrix ρ built from a compactly supported correlation function. By the Schur product theorem, the element-wise product of two positive semi-definite matrices is positive semi-definite — so as long as the taper is itself a valid correlation matrix (Gaspari-Cohn and SOAR are; a hard cutoff is not, in general), localization cannot break the PSD-ness of the covariance.

    gaspari_cohn and localization_matrix delegate to their gaussx counterparts with support parameter c = 2 * radius (gaussx parameterises by the compact-support length, filterax by the half-width); the distance metrics (euclidean_distance, haversine_distance) are re-exported from gaussx unchanged. Wrap these primitives in an AbstractLocalizer to plug them into the Layer-2 loops as a drop-in component; the LETKF instead applies localization in observation space, per grid point, and localized_kalman_gain tapers the gain itself.

    Taper functions¶

    Map a distance array to weights in [0, 1]. Gaspari-Cohn is the production default (compactly supported, exactly zero beyond 2 * radius); Gaussian and SOAR decay smoothly without compact support; the hard cutoff is a diagnostic tool rather than a valid correlation function.

    filterax — differentiable ensemble Kalman filters and processes for JAX.

    gaspari_cohn(distances: Float[Array, '...'], radius: float) -> Float[Array, '...'] ¶

    Gaspari-Cohn fifth-order compactly supported taper.

    With z = |d| / ℓ, the piecewise rational

    ρ(z) = −¼ z⁵ + ½ z⁴ + ⅝ z³ − (5/3) z² + 1                       0 ≤ z ≤ 1
ρ(z) = (1/12) z⁵ − ½ z⁴ + ⅝ z³ + (5/3) z² − 5 z + 4 − 2 / (3 z)   1 < z < 2
ρ(z) = 0                                                        z ≥ 2

    so ρ = 1 at d = 0 and ρ = 0 for |d| ≥ 2 ℓ. It is positive definite, and C² in d. Wraps gaussx.gaspari_cohn, which is parameterised by the compact support c and guards the 2 / (3 z) term so that reverse-mode gradients stay finite at d = 0. This function takes the half-width instead, with c = 2 ℓ.

    def gaspari_cohn(
    distances: Float[Array, "..."],
    radius: float,
) -> Float[Array, "..."]:
    """Gaspari-Cohn fifth-order compactly supported taper.

    With z = |d| / ℓ, the piecewise rational

        ρ(z) = −¼ z⁵ + ½ z⁴ + ⅝ z³ − (5/3) z² + 1                       0 ≤ z ≤ 1
        ρ(z) = (1/12) z⁵ − ½ z⁴ + ⅝ z³ + (5/3) z² − 5 z + 4 − 2 / (3 z)   1 < z < 2
        ρ(z) = 0                                                        z ≥ 2

    so ρ = 1 at d = 0 and ρ = 0 for |d| ≥ 2 ℓ. It is positive definite, and C² in d.
    Wraps `gaussx.gaspari_cohn`, which is parameterised by the compact support c and
    guards the 2 / (3 z) term so that reverse-mode gradients stay finite at d = 0. This
    function takes the half-width instead, with c = 2 ℓ.

    Args:
        distances: Distances d of any shape, e.g. a pairwise distance matrix.
        radius: Half-width ℓ > 0; ρ = 0 beyond |d| = 2 ℓ.

    Returns:
        Taper values in [0, 1], with the shape of ``distances``.

    Examples:
        One at zero distance and zero beyond twice the half-width:

        >>> import jax.numpy as jnp
        >>> import filterax
        >>> distances = jnp.array([0.0, 2.0, 3.0])
        >>> filterax.gaspari_cohn(distances, radius=1.0).tolist()
        [1.0, 0.0, 0.0]

        The gradient stays finite at d = 0:

        >>> import jax
        >>> slope = jax.grad(lambda d: filterax.gaspari_cohn(d, 1.0))(jnp.array(0.0))
        >>> bool(jnp.isfinite(slope))
        True

    References:
        Gaspari & Cohn (1999), *Q. J. R. Meteorol. Soc.* 125, 723–757.
    """
    # c = 2 ℓ
    support_radius = 2.0 * radius
    # ρ(z),   z = 2 |d| / c = |d| / ℓ
    return gaussx.gaspari_cohn(distances, support_radius)

    def hard_cutoff(
    distances: Float[Array, "..."],
    radius: float,
) -> Float[Array, "..."]:
    """Binary taper, a debugging baseline.

        ρ(d) = 1 for d ≤ ℓ,   ρ(d) = 0 for d > ℓ

    It is discontinuous at d = ℓ and not positive definite in general, so the localized
    matrix may lose positive semi-definiteness, which can destabilise a filter. Prefer
    `gaspari_cohn` or `gaussian_taper` in production.

    Args:
        distances: Distances d of any shape.
        radius: Cutoff radius ℓ > 0.

    Returns:
        Indicator weights with the shape and dtype of ``distances``.

    Examples:
        The cutoff itself is kept:

        >>> import jax.numpy as jnp
        >>> import filterax
        >>> filterax.hard_cutoff(jnp.array([0.5, 1.0, 1.5]), radius=1.0).tolist()
        [1.0, 1.0, 0.0]

        The dtype of the distances is preserved:

        >>> distances = jnp.array([0.5], dtype=jnp.float32)
        >>> filterax.hard_cutoff(distances, radius=1.0).dtype == distances.dtype
        True
    """
    # d ≤ ℓ
    within_radius = distances <= radius
    # ρ(d)
    weights = jnp.where(within_radius, 1.0, 0.0)
    return weights.astype(distances.dtype)

    localization_matrix fuses a pairwise distance computation with the Gaspari-Cohn taper, producing the dense ρ consumed by localize and localized_kalman_gain. Use haversine_distance as the metric for spherical (lat, lon)-in-radians grids.

    def localization_matrix(
    coords_a: Float[Array, "N_a D"],
    coords_b: Float[Array, "N_b D"],
    radius: float,
    *,
    metric: Callable[
        [Float[Array, "N_a D"], Float[Array, "N_b D"]], Float[Array, "N_a N_b"]
    ] = euclidean_distance,
) -> Float[Array, "N_a N_b"]:
    """Pairwise Gaspari-Cohn taper between two sets of coordinates.

        ρᵢⱼ = ρ(d(aᵢ, bⱼ); ℓ)

    Builds the dense ρ_xy and ρ_yy consumed by `localize` and `localized_kalman_gain`.
    Wraps `gaussx.localization_matrix`, whose radius is the compact support c, with
    c = 2 ℓ, so it matches ``gaspari_cohn(metric(a, b), radius)`` entry for entry.

    Args:
        coords_a: First set of points aᵢ, one row per point.
        coords_b: Second set of points bⱼ, one row per point.
        radius: Half-width ℓ > 0; the weights vanish beyond 2 ℓ.
        metric: Pairwise distance function d returning one row per point of a and one
            column per point of b. Defaults to `euclidean_distance`; pass
            `haversine_distance` for spherical grids with (latitude, longitude) in
            radians.

    Returns:
        The taper matrix ρ, with entries in [0, 1].

    Examples:
        Three points on a line, with a unit half-width:

        >>> import jax.numpy as jnp
        >>> import filterax
        >>> grid = jnp.array([[0.0], [1.0], [2.0]])
        >>> rho = filterax.localization_matrix(grid, grid, radius=1.0)
        >>> rho.shape, float(rho[0, 0]), float(rho[0, 2])
        ((3, 3), 1.0, 0.0)

        It is the taper of the distance matrix, entry for entry:

        >>> distance = filterax.euclidean_distance(grid, grid)
        >>> taper = filterax.gaspari_cohn(distance, radius=1.0)
        >>> bool(jnp.array_equal(rho, taper))
        True
    """
    # c = 2 ℓ
    support_radius = 2.0 * radius
    # ρᵢⱼ = ρ(d(aᵢ, bⱼ); c)
    return gaussx.localization_matrix(coords_a, coords_b, support_radius, metric=metric)

    def euclidean_distance(
    coords_a: Float[Array, "Na D"],
    coords_b: Float[Array, "Nb D"],
) -> Float[Array, "Na Nb"]:
    """Pairwise Euclidean distances ‖aₙ − bₘ‖₂.

    A default ``metric`` for `localization_matrix`. It builds on
    `stable_squared_distances` and takes a gradient-safe square root, so zero
    distances (the diagonal of a self-distance matrix) give no ``NaN``
    gradients.

    Args:
        coords_a: First set of points aₙ, one row per point.
        coords_b: Second set of points bₘ, one row per point.

    Returns:
        The matrix of distances ‖aₙ − bₘ‖₂.

    Examples:
        A 3-4-5 triangle:

        >>> import jax.numpy as jnp
        >>> import gaussx
        >>> origin = jnp.zeros((1, 2))
        >>> point = jnp.array([[3.0, 4.0]])
        >>> bool(jnp.allclose(gaussx.euclidean_distance(origin, point), 5.0))
        True

        One row and one column per point:

        >>> gaussx.euclidean_distance(jnp.zeros((3, 2)), jnp.ones((4, 2))).shape
        (3, 4)
    """
    # ‖aₙ − bₘ‖₂²
    squared_distance = stable_squared_distances(
        coords_a,
        coords_b,
        compute_dtype=coords_a.dtype,
        accumulate_dtype=coords_a.dtype,
    )
    # The square root has an infinite slope at zero, so keep zero out of it.
    safe_squared_distance = jnp.where(squared_distance > 0.0, squared_distance, 1.0)
    # ‖aₙ − bₘ‖₂
    return jnp.where(squared_distance > 0.0, jnp.sqrt(safe_squared_distance), 0.0)

    coords_a: Float[Array, "Na 2"],
    coords_b: Float[Array, "Nb 2"],
    radius: float = 6.371e6,
) -> Float[Array, "Na Nb"]:
    """Pairwise great-circle (haversine) distances on a sphere.

        h = sin²(Δφ / 2) + cos φ_a cos φ_b sin²(Δϑ / 2)
        d = 2 r arcsin(√h)

    A ``metric`` for `localization_matrix` on geophysical grids, with latitude
    φ and longitude ϑ in **radians**.

    Algorithm:
        1. Broadcast the latitudes and longitudes to one row per point of a
           and one column per point of b.
        2. Form the haversine h, clipped to [0, 1] against round-off.
        3. Return the arc length 2 r arcsin(√h).

    Args:
        coords_a: First set of points (φ, ϑ) in radians, one row per point.
        coords_b: Second set of points (φ, ϑ) in radians, one row per point.
        radius: Sphere radius r in the units of the returned distance; the
            default is the Earth mean radius, 6.371e6 m.

    Returns:
        The matrix of great-circle distances d.

    Examples:
        A quarter of the unit circle along the equator:

        >>> import jax.numpy as jnp
        >>> import gaussx
        >>> origin = jnp.zeros((1, 2))
        >>> east = jnp.array([[0.0, jnp.pi / 2]])
        >>> distance = gaussx.haversine_distance(origin, east, radius=1.0)
        >>> bool(jnp.allclose(distance, jnp.pi / 2))
        True

        As the metric of a localization taper:

        >>> gaussx.localization_matrix(
        ...     origin, east, 1.0, metric=gaussx.haversine_distance
        ... ).shape
        (1, 1)
    """
    # jnp, not einx: N_a = 0 or N_b = 0 returns an empty matrix here today, and
    # einx raises AxisSizeError on a zero-length axis.
    latitude_a = coords_a[:, 0][:, None]
    longitude_a = coords_a[:, 1][:, None]
    latitude_b = coords_b[:, 0][None, :]
    longitude_b = coords_b[:, 1][None, :]
    # Δφ = φ_b − φ_a
    latitude_difference = latitude_b - latitude_a
    # Δϑ = ϑ_b − ϑ_a
    longitude_difference = longitude_b - longitude_a
    # h = sin²(Δφ / 2) + cos φ_a cos φ_b sin²(Δϑ / 2)
    haversine = (
        jnp.sin(latitude_difference / 2.0) ** 2
        + jnp.cos(latitude_a)
        * jnp.cos(latitude_b)
        * jnp.sin(longitude_difference / 2.0) ** 2
    )
    # d = 2 r arcsin(√h)
    return 2.0 * radius * jnp.arcsin(jnp.sqrt(jnp.clip(haversine, 0.0, 1.0)))

    Kalman gain with Schur-product localization of both sample covariances.

    G = (ρ_xy ∘ Σ̂_xy) (ρ_yy ∘ Σ̂_h + Σ_ε)⁻¹

    Wraps gaussx.localized_kalman_gain and fixes bessel=True, the divisor N_ℰ − 1. Tapering suppresses spurious long-range sample correlations, and by the Schur product theorem ρ_yy ∘ Σ̂_h stays positive semi-definite when ρ_yy is. Build the tapers with localization_matrix.

    1. Form the sample covariances Σ̂_xy and Σ̂_h.
    2. Taper them by ρ_xy and ρ_yy.
    3. Add Σ_ε and symmetrise.
    4. Solve for the gain G row by row.

    def adaptive_localization(
    state_particles: Float[Array, "N_e N_x"],
    obs_particles: Float[Array, "N_e N_y"],
    *,
    significance: float = 1.0,
) -> Float[Array, "N_x N_y"]:
    """Adaptive weights from the sampling noise of ensemble correlations.

        rᵢⱼ = [Σ̂_xy]ᵢⱼ / (σ_x,i σ_h,j),   se(r) ≈ (1 − r²) / √(N_ℰ − 2)
        ρᵢⱼ = 1 if |rᵢⱼ| > s se(rᵢⱼ),   ρᵢⱼ = 0 otherwise

    Keeps a pair at unit weight, a hard mask, when its sample correlation r exceeds s
    standard errors of sampling noise. The weights multiply the gain by the Schur
    product, which suppresses long-range correlations driven by noise rather than by
    physical structure.

    Unlike a distance taper, this has no half-width to tune. In exchange it needs enough
    members for the noise floor to be informative, typically N_ℰ ≥ 20, and costs an
    extra O(N_ℰ D_x D_y) per window.

    Algorithm:
        1. Check that N_ℰ ≥ 3, so that √(N_ℰ − 2) is defined.
        2. Take the sample spreads σ_x and σ_h with the divisor N_ℰ − 1.
        3. Divide Σ̂_xy by the outer product of the spreads to get r.
        4. Compare |r| with s se(r), floored at zero.

    Args:
        state_particles: Prior ensemble x⁽ᵉ⁾ in state space, one row per member.
        obs_particles: Its image h⁽ᵉ⁾ = h(x⁽ᵉ⁾) in observation space.
        significance: Threshold s on se(r); larger zeroes more pairs.

    Returns:
        The weight matrix ρ, with entries in {0, 1}, in the dtype of
        ``state_particles``.

    Raises:
        ValueError: If N_ℰ < 3, where the noise floor is undefined.

    Examples:
        An observation of the first component keeps that pair at unit weight:

        >>> import jax.random as jr
        >>> import filterax
        >>> state = jr.normal(jr.key(0), (20, 2))
        >>> weights = filterax.adaptive_localization(state, state[:, :1])
        >>> weights.shape, float(weights[0, 0])
        ((2, 1), 1.0)

        Two members cannot supply a noise floor:

        >>> filterax.adaptive_localization(
        ...     state[:2], state[:2, :1]
        ... )  # doctest: +NORMALIZE_WHITESPACE
        Traceback (most recent call last):
        ...
        ValueError: adaptive_localization needs N_e ≥ 3 so the √(N_e − 2)
        sampling-noise floor is defined; got N_e=2.

    References:
        Anderson (2007), *Physica D* 230, 99-111.
    """
    ensemble_size = state_particles.shape[0]
    # √(N_ℰ − 2) appears in the sampling-noise denominator, which also covers the
    # N_ℰ ≥ 2 the Bessel-corrected spread needs.
    if ensemble_size < 3:
        raise ValueError(
            "adaptive_localization needs N_e ≥ 3 so the √(N_e − 2) "
            f"sampling-noise floor is defined; got N_e={ensemble_size}."
        )
    # jnp, not einx: D_x = 0 or D_y = 0 returns an empty matrix here today, and einx
    # raises AxisSizeError on a zero-length axis.
    # σ_x
    state_spread = jnp.std(state_particles, axis=0, ddof=1)
    # σ_h
    obs_spread = jnp.std(obs_particles, axis=0, ddof=1)
    # Σ̂_xy
    cross_covariance = gaussx.ensemble_cross_covariance(
        state_particles, obs_particles, bessel=True
    )
    # σ_x σ_hᵀ
    spread_product = jnp.outer(state_spread, obs_spread)
    # Floored, so that a collapsed coordinate gives r = 0 rather than a division by 0.
    safe_spread_product = jnp.maximum(spread_product, 1e-30)
    # r
    correlation = cross_covariance / safe_spread_product
    # 1 − r²
    unexplained = 1.0 - correlation * correlation
    # √(N_ℰ − 2)
    root_members = jnp.sqrt(jnp.asarray(ensemble_size - 2, dtype=correlation.dtype))
    # se(r) = (1 − r²) / √(N_ℰ − 2)
    standard_error = unexplained / root_members
    # |r|
    correlation_size = jnp.abs(correlation)
    # max(se(r), 0), since round-off can take |r| just above 1
    floored_error = jnp.maximum(standard_error, 0.0)
    # s se(r)
    threshold = significance * floored_error
    # ρ = 1 where |r| > s se(r)
    keep = correlation_size > threshold
    return keep.astype(state_particles.dtype)
