    Inflation¶

    Counteract spread collapse from finite-ensemble, model-error, or localization-side-effect sources. Two flavours of primitive:

    • Drop-in inflators — MultiplicativeInflator, RTPS, RTPP, AdditiveInflator all implement AbstractInflator and plug straight into the Layer-2 assimilation loops (filterax.ETKF, LETKF, …).
    • Helper primitives — inflate_adaptive returns a posterior on the multiplicative factor λ (the caller composes it with a fresh MultiplicativeInflator(factor=μ_post) on the next cycle); ledoit_wolf_shrinkage returns a regularised covariance matrix, not an inflated ensemble. Neither is an AbstractInflator, so they are driven from custom loops rather than dropped into L2 models.

    The classic trio of functional primitives — inflate_multiplicative, inflate_rtps, inflate_rtpp — delegates to the corresponding gaussx primitives (gaussx.inflate_multiplicative, gaussx.inflate_rtps, gaussx.inflate_rtpp); filterax adds the EnKF-flavoured conventions and the inflator classes on top.

    Picking an inflator¶

    Method Mean-preserving? Tunable Use when
    MultiplicativeInflator / inflate_multiplicative Yes factor Simple scalar inflation; production default
    RTPS / inflate_rtps Yes (per-variable spread) alpha ∈ [0, 1] Per-variable adaptive recovery of forecast spread (Whitaker & Hamill 2012)
    RTPP / inflate_rtpp Yes alpha ∈ [0, 1] Full-anomaly blend that preserves inter-variable correlation (Zhang et al. 2004)
    AdditiveInflator / inflate_additive Yes (after recentring) Q_add Explicit model-error injection (Hamill & Whitaker 2005)
    inflate_adaptive (Anderson 2009 prior update) prior (μ_λ, σ²_λ) Self-tuning multiplicative inflation; carry posterior across cycles
    ledoit_wolf_shrinkage n/a (returns covariance) none (analytic optimum) Regularise the rank-deficient sample covariance when Nₑ ≪ Nₓ

    class MultiplicativeInflator(AbstractInflator, strict=True):
    """Multiplicative inflation about the sample mean, as a module.

        x⁽ᵉ⁾ ← x̄ + ζ (x⁽ᵉ⁾ − x̄)

    Wraps `inflate_multiplicative`. It ignores ``forecast_particles`` and any extra
    keywords.

    Attributes:
        factor: Inflation factor ζ > 0; values in [1.01, 1.10] are typical.

    Examples:
        Doubling the spread keeps the mean:

        >>> import jax.numpy as jnp
        >>> import filterax
        >>> inflator = filterax.MultiplicativeInflator(factor=2.0)
        >>> inflator(jnp.array([[0.0], [2.0]])).tolist()

        >>> particles = jnp.array([[0.0], [2.0]])
        >>> inflator(particles, particles, step=3).tolist()
        [[-1.0], [3.0]]
    """

    factor: float = eqx.field(static=True)

    def __call__(
        self,
        particles: Float[Array, "N_e N_x"],
        forecast_particles: Float[Array, "N_e N_x"] | None = None,
        **_: Any,
    ) -> Float[Array, "N_e N_x"]:
        del forecast_particles
        # x⁽ᵉ⁾ ← x̄ + ζ (x⁽ᵉ⁾ − x̄)
        return inflate_multiplicative(particles, self.factor)

    AdditiveInflator ¶

    Bases: AbstractInflator

    Additive Gaussian inflation with a fresh key per window, as a module.

    x⁽ᵉ⁾ ← x⁽ᵉ⁾ + η⁽ᵉ⁾ − η̄,   η⁽ᵉ⁾ ~ 𝒩(0, Σ_η)

    Wraps inflate_additive and adds the choice of key. Inside the run loops (filterax.ETKF, filterax.LETKF, …) the loop passes step=, so successive windows draw independent noise from jr.fold_in(base_key, step). In your own loop, pass step= yourself, or an explicit key=, which takes precedence. Calling with neither reuses base_key and yields the same draw every time, which is fine once but a trap across windows.

    Attributes:

    Name Type Description
    noise_cov AbstractLinearOperator

    Model-error covariance Σ_η.
    base_key PRNGKeyArray

    PRNG key, folded with the per-call step, or used as it is when neither step nor key is given.

    Examples:

    The noise is centred, so the ensemble mean stays where it was:

    >>> import jax.numpy as jnp
>>> import jax.random as jr
>>> import lineax as lx
>>> import filterax
>>> inflator = filterax.AdditiveInflator(
...     noise_cov=lx.DiagonalLinearOperator(0.1 * jnp.ones(2)),
...     base_key=jr.key(0),
... )
>>> first = inflator(jnp.zeros((4, 2)), step=0)
>>> first.shape
(4, 2)
>>> bool(jnp.allclose(filterax.ensemble_mean(first), 0.0, atol=1e-6))
True

    Another window draws other noise, and the same window repeats its draw:

    >>> second = inflator(jnp.zeros((4, 2)), step=1)
>>> bool(jnp.allclose(first, second))
False
>>> bool(jnp.array_equal(first, inflator(jnp.zeros((4, 2)), step=0)))
True

    class AdditiveInflator(AbstractInflator, strict=True):
    """Additive Gaussian inflation with a fresh key per window, as a module.

        x⁽ᵉ⁾ ← x⁽ᵉ⁾ + η⁽ᵉ⁾ − η̄,   η⁽ᵉ⁾ ~ 𝒩(0, Σ_η)

    Wraps `inflate_additive` and adds the choice of key. Inside the run loops
    (`filterax.ETKF`, `filterax.LETKF`, …) the loop passes ``step=``, so successive
    windows draw independent noise from ``jr.fold_in(base_key, step)``. In your own
    loop, pass ``step=`` yourself, or an explicit ``key=``, which takes precedence.
    Calling with neither reuses ``base_key`` and yields the same draw every time,
    which is fine once but a trap across windows.

    Attributes:
        noise_cov: Model-error covariance Σ_η.
        base_key: PRNG key, folded with the per-call ``step``, or used as it is when
            neither ``step`` nor ``key`` is given.

    Examples:
        The noise is centred, so the ensemble mean stays where it was:

        >>> import jax.numpy as jnp
        >>> import jax.random as jr
        >>> import lineax as lx
        >>> import filterax
        >>> inflator = filterax.AdditiveInflator(
        ...     noise_cov=lx.DiagonalLinearOperator(0.1 * jnp.ones(2)),
        ...     base_key=jr.key(0),
        ... )
        >>> first = inflator(jnp.zeros((4, 2)), step=0)
        >>> first.shape
        (4, 2)
        >>> bool(jnp.allclose(filterax.ensemble_mean(first), 0.0, atol=1e-6))
        True

        Another window draws other noise, and the same window repeats its draw:

        >>> second = inflator(jnp.zeros((4, 2)), step=1)
        >>> bool(jnp.allclose(first, second))
        False
        >>> bool(jnp.array_equal(first, inflator(jnp.zeros((4, 2)), step=0)))
        True
    """

    noise_cov: lx.AbstractLinearOperator
    base_key: PRNGKeyArray

    def __call__(
        self,
        particles: Float[Array, "N_e N_x"],
        forecast_particles: Float[Array, "N_e N_x"] | None = None,
        *,
        key: PRNGKeyArray | None = None,
        step: int | jnp.ndarray | None = None,
        **_: Any,
    ) -> Float[Array, "N_e N_x"]:
        del forecast_particles
        if key is not None:
            call_key = key
        elif step is not None:
            call_step = jnp.asarray(step, dtype=jnp.int32)
            call_key = jr.fold_in(self.base_key, call_step)
        else:
            call_key = self.base_key
        # x⁽ᵉ⁾ ← x⁽ᵉ⁾ + η⁽ᵉ⁾ − η̄
        return inflate_additive(call_key, particles, self.noise_cov)

    inflation_mean: Float[Array, ""] | float,
    inflation_var: Float[Array, ""] | float,
    innovation: Float[Array, " N_y"],
    innovation_cov: Float[Array, "N_y N_y"],
    *,
    min_factor: float = 1.0,
    max_factor: float = 1.2,
) -> tuple[Float[Array, ""], Float[Array, ""]]:
    """Bayesian update of a multiplicative inflation factor.

        ζ̂_obs = clip(r̄ᵀ Σ_y⁻¹ r̄ / D_y, ζ_min, ζ_max),   σ²_obs = 2 / D_y
        μ_ζ|y = (σ²_ζ ζ̂_obs + σ²_obs μ_ζ) / (σ²_ζ + σ²_obs)
        σ²_ζ|y = σ²_ζ σ²_obs / (σ²_ζ + σ²_obs)

    Treats ζ as a random variable with the Gaussian prior ζ ~ 𝒩(μ_ζ, σ²_ζ) and updates
    it from the normalised residual of the window, in a simplified form of Anderson
    (2009). A correctly specified Σ_y has 𝔼[χ² / D_y] = 1, and an underdispersive
    ensemble pulls ζ̂_obs above 1. The posterior is the Gaussian product of the prior
    with a likelihood centred at ζ̂_obs, whose variance σ²_obs is that of χ² / D_y.

    The posterior comes back as JAX scalars, so it can be carried through `jax.jit`,
    `jax.grad` and `jax.lax.scan` across windows. To inflate an ensemble, pass μ_ζ|y to
    `inflate_multiplicative`.

    Algorithm:
        1. Form χ² = r̄ᵀ Σ_y⁻¹ r̄ with one solve.
        2. Clamp χ² / D_y to [ζ_min, ζ_max] to get ζ̂_obs.
        3. Multiply the Gaussian prior by the likelihood.

    Args:
        inflation_mean: Prior mean μ_ζ.
        inflation_var: Prior variance σ²_ζ.
        innovation: Mean residual r̄ = y − h̄.
        innovation_cov: Dense innovation covariance Σ_y, taken as positive
            semi-definite. For typical D_y a dense solve is cheaper than assembling a
            structured operator; build it with ``as_matrix()`` at the call site.
        min_factor: Lower clamp ζ_min on the data-implied estimate.
        max_factor: Upper clamp ζ_max on the data-implied estimate.

    Returns:
        Tuple ``(posterior_mean, posterior_variance)`` holding μ_ζ|y and σ²_ζ|y, which
        serve as the prior of the next window.

    Raises:
        ZeroDivisionError: If D_y = 0.

    Examples:
        A residual far larger than Σ_y allows pulls the factor up, and the posterior
        variance shrinks:

        >>> import jax.numpy as jnp
        >>> import filterax
        >>> innovation = jnp.array([3.0, -3.0])
        >>> innovation_cov = jnp.eye(2)
        >>> mean, variance = filterax.inflate_adaptive(
        ...     1.0, 0.01, innovation, innovation_cov
        ... )
        >>> bool(mean > 1.0), bool(variance < 0.01)
        (True, True)

        With no prior variance the prior wins:

        >>> mean, variance = filterax.inflate_adaptive(
        ...     1.05, 0.0, innovation, innovation_cov
        ... )
        >>> bool(jnp.allclose(mean, 1.05)), float(variance)
        (True, 0.0)

        The posterior inflates an ensemble directly:

        >>> particles = jnp.array([[0.0], [2.0]])
        >>> filterax.inflate_multiplicative(particles, mean).shape
        (2, 1)

    References:
        Anderson (2009), *Tellus A* 61, 72-83.
    """
    obs_size = innovation.shape[0]
    covariance_op = lx.MatrixLinearOperator(
        innovation_cov, lx.positive_semidefinite_tag
    )
    # χ² = r̄ᵀ Σ_y⁻¹ r̄
    chi_squared = gaussx.quadratic_form(covariance_op, innovation)
    # χ² / D_y
    normalised_chi_squared = chi_squared / obs_size
    # ζ̂_obs, clamped to keep the estimate from running away on outlier residuals
    factor_estimate = jnp.clip(normalised_chi_squared, min_factor, max_factor)
    # σ²_obs = 2 / D_y
    obs_variance = jnp.asarray(2.0 / obs_size, dtype=normalised_chi_squared.dtype)
    # μ_ζ
    prior_mean = jnp.asarray(inflation_mean, dtype=normalised_chi_squared.dtype)
    # σ²_ζ
    prior_variance = jnp.asarray(inflation_var, dtype=normalised_chi_squared.dtype)
    # σ²_ζ + σ²_obs
    total_variance = prior_variance + obs_variance
    # σ²_ζ ζ̂_obs
    weighted_estimate = prior_variance * factor_estimate
    # σ²_obs μ_ζ
    weighted_prior = obs_variance * prior_mean
    # μ_ζ|y = (σ²_ζ ζ̂_obs + σ²_obs μ_ζ) / (σ²_ζ + σ²_obs)
    posterior_mean = (weighted_estimate + weighted_prior) / total_variance
    # σ²_ζ σ²_obs
    variance_product = prior_variance * obs_variance
    # σ²_ζ|y = σ²_ζ σ²_obs / (σ²_ζ + σ²_obs)
    posterior_variance = variance_product / total_variance
    return posterior_mean, posterior_variance

        as a scalar array, so that the function composes with `jax.jit`, `jax.vmap`
        and `jax.grad`.

    Raises:
        ValueError: If N_ℰ < 2, where the divisor N_ℰ − 1 is undefined.

    Examples:
        Few members in a large state need heavy shrinkage:

        >>> import jax.numpy as jnp
        >>> import jax.random as jr
        >>> import filterax
        >>> particles = jr.normal(jr.key(0), (10, 200))
        >>> covariance, shrinkage = filterax.ledoit_wolf_shrinkage(particles)
        >>> covariance.shape
        (200, 200)
        >>> bool(0.5 < shrinkage <= 1.0)
        True

        One member has no sample covariance:

        >>> filterax.ledoit_wolf_shrinkage(
        ...     particles[:1]
        ... )  # doctest: +NORMALIZE_WHITESPACE
        Traceback (most recent call last):
        ...
        ValueError: particles must contain at least 2 ensemble members for the
        Bessel-corrected estimators to be well-defined; got N_e=1.

    References:
        Ledoit & Wolf (2004), *J. Multivariate Anal.* 88, 365-411.
    """
    check_ensemble_size(particles.shape[0])
    # Σ̂_λ as an operator, and λ
    shrunk_operator, shrinkage = gaussx.ledoit_wolf_shrinkage(particles)
    # Σ̂_λ
    shrunk_covariance = shrunk_operator.as_matrix()
    return shrunk_covariance, shrinkage

    Composition pattern¶

    The L2 models (filterax.ETKF, filterax.LETKF, …) accept any AbstractInflator instance. To carry stateful inflation (e.g. adaptive λ) across cycles, drive the loop yourself with the L1 components:

    import filterax as flx

# Anderson 2009: carry (μ_λ, σ²_λ) across cycles.
mu, var = 1.0, 0.01
inflator = flx.MultiplicativeInflator(factor=mu)

for obs, time in observations:
    forecast = vmap_dynamics(particles, t_prev, time)
    result = flx.filters.ETKF().analysis(forecast, obs, obs_op, R)

    # Update the inflation belief from this cycle's innovation.
    S = flx.innovation_covariance(vmap(obs_op)(forecast), R).as_matrix()
    innov = obs - vmap(obs_op)(forecast).mean(axis=0)
    mu, var = flx.inflate_adaptive(mu, var, innov, S)
    inflator = flx.MultiplicativeInflator(factor=mu)

    particles = inflator(result.particles, forecast)
