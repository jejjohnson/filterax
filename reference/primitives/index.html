    Primitives¶

    Pure functions on arrays and operators. Stateless, differentiable, composable; compatible with jax.jit, jax.grad, and eqx.filter_vmap. Every filter and smoother in the package is assembled from these.

    Heavy linear algebra is delegated to gaussx: ensemble_covariance returns a gaussx.LowRankUpdate operator (rank N_e, never a dense (N_x, N_x) matrix), and the solves inside kalman_gain and log_likelihood dispatch through gaussx's structural solver — a Woodbury / matrix-determinant-lemma path for low-rank updates — with an optional solver= keyword to override the strategy.

    Localization tapers and inflation primitives have their own pages: Localization and Inflation.

    Ensemble statistics¶

    Bessel-corrected moments of an (N_e, N_x) ensemble: mean, centred anomalies, and the (cross-)covariances built from them.

    filterax — differentiable ensemble Kalman filters and processes for JAX.

    def ensemble_mean(
    particles: Float[Array, "N_e N_x"],
) -> Float[Array, " N_x"]:
    """Sample mean of an ensemble.

        x̄ = (1 / N_ℰ) ∑ₑ x⁽ᵉ⁾

    Args:
        particles: Ensemble members x⁽ᵉ⁾, one row per member.

    Returns:
        The ensemble mean x̄.

    Raises:
        AxisSizeError: From einx, if N_ℰ = 0 or D_x = 0.

    Examples:
        Two members in two dimensions:

        >>> import jax.numpy as jnp
        >>> import filterax
        >>> particles = jnp.array([[0.0, 1.0], [2.0, 3.0]])
        >>> filterax.ensemble_mean(particles).tolist()
        [1.0, 2.0]

        One member is its own mean:

        >>> filterax.ensemble_mean(particles[:1]).tolist()
        [0.0, 1.0]
    """
    # x̄ = (1 / N_ℰ) ∑ₑ x⁽ᵉ⁾
    return einx.mean("e x -> x", particles)

    def ensemble_anomalies(
    particles: Float[Array, "N_e N_x"],
) -> Float[Array, "N_e N_x"]:
    """State anomalies of an ensemble about its sample mean.

        x̃⁽ᵉ⁾ = x⁽ᵉ⁾ − x̄

    The rows of X̃ sum to zero by construction. X̃ is the input to the covariance and
    gain recipes: every ensemble Kalman filter is some choice of square root applied
    to these anomalies.

    Args:
        particles: Ensemble members x⁽ᵉ⁾, one row per member.

    Returns:
        The anomalies X̃, with rows x̃⁽ᵉ⁾.

    Raises:
        AxisSizeError: From einx, if N_ℰ = 0 or D_x = 0.

    Examples:
        Two members about their mean:

        >>> import jax.numpy as jnp
        >>> import filterax
        >>> particles = jnp.array([[0.0, 1.0], [2.0, 3.0]])
        >>> filterax.ensemble_anomalies(particles).tolist()
        [[-1.0, -1.0], [1.0, 1.0]]

        One member has no spread:

        >>> filterax.ensemble_anomalies(particles[:1]).tolist()
        [[0.0, 0.0]]
    """
    # x̄ = (1 / N_ℰ) ∑ₑ x⁽ᵉ⁾
    mean = ensemble_mean(particles)
    # x̃⁽ᵉ⁾ = x⁽ᵉ⁾ − x̄
    return einx.subtract("e x, x -> e x", particles, mean)

    Kalman gain¶

    For the Schur-tapered variant that suppresses spurious long-range correlations, see localized_kalman_gain on the Localization page.

    filterax — differentiable ensemble Kalman filters and processes for JAX.

    kalman_gain(particles: Float[Array, 'N_e N_x'], obs_particles: Float[Array, 'N_e N_y'], obs_noise: lx.AbstractLinearOperator, *, solver: gaussx.AbstractSolverStrategy | None = None, dense_innovation: bool | None = None) -> Float[Array, 'N_x N_y'] ¶

    Kalman gain from an ensemble and its image in observation space.

    G = Σ̂_xy Σ̂_y⁻¹,   Σ̂_y = Σ̂_h + Σ_ε

    Wraps gaussx.ensemble_kalman_gain and fixes bessel=True, the divisor N_ℰ − 1. Σ̂_y is assembled by one of two routes, which agree to round-off. With U = H̃ᵀ / √(N_ℰ − 1), the Woodbury route solves through

    Σ̂_y⁻¹ = Σ_ε⁻¹ − Σ_ε⁻¹ U (I + Uᵀ Σ_ε⁻¹ U)⁻¹ Uᵀ Σ_ε⁻¹
    • Woodbury, the default when N_ℰ < D_y: Σ̂_y is a gaussx.LowRankUpdate of Σ_ε, solved by structural dispatch at O(N_ℰ² D_y + N_ℰ³), and a structured Σ_ε is never materialised.
    • Dense, the default when N_ℰ ≥ D_y: Σ̂_y is formed as a (D_y, D_y) matrix and solved directly at O(N_ℰ D_y² + D_y³), because the capacitance would be the larger matrix. It also handles a positive semi-definite Σ_ε, which Woodbury cannot.
    Algorithm
    1. Choose the route for Σ̂_y from the shapes or dense_innovation.
    2. Form the cross-covariance Σ̂_xy.
    3. Assemble Σ̂_y densely, or as a low-rank update of Σ_ε.
    4. Solve for the gain G = Σ̂_xy Σ̂_y⁻¹ row by row.

    		 required

    		 required

    Solver strategy for Σ̂_y; None uses structural dispatch. A matrix-free strategy wants dense_innovation=False, so that it gets the structured operator.

    		 None

    Whether to form the (D_y, D_y) Σ̂_y densely. None chooses by shape; True and False force the dense and the Woodbury route.

    		 None

    def kalman_gain(
    particles: Float[Array, "N_e N_x"],
    obs_particles: Float[Array, "N_e N_y"],
    obs_noise: lx.AbstractLinearOperator,
    *,
    solver: gaussx.AbstractSolverStrategy | None = None,
    dense_innovation: bool | None = None,
) -> Float[Array, "N_x N_y"]:
    """Kalman gain from an ensemble and its image in observation space.

        G = Σ̂_xy Σ̂_y⁻¹,   Σ̂_y = Σ̂_h + Σ_ε

    Wraps `gaussx.ensemble_kalman_gain` and fixes ``bessel=True``, the divisor
    N_ℰ − 1. Σ̂_y is assembled by one of two routes, which agree to round-off. With
    U = H̃ᵀ / √(N_ℰ − 1), the Woodbury route solves through

        Σ̂_y⁻¹ = Σ_ε⁻¹ − Σ_ε⁻¹ U (I + Uᵀ Σ_ε⁻¹ U)⁻¹ Uᵀ Σ_ε⁻¹

    - **Woodbury**, the default when N_ℰ < D_y: Σ̂_y is a `gaussx.LowRankUpdate` of
      Σ_ε, solved by structural dispatch at O(N_ℰ² D_y + N_ℰ³), and a structured Σ_ε
      is never materialised.
    - **Dense**, the default when N_ℰ ≥ D_y: Σ̂_y is formed as a (D_y, D_y) matrix and
      solved directly at O(N_ℰ D_y² + D_y³), because the capacitance would be the
      larger matrix. It also handles a positive semi-definite Σ_ε, which Woodbury
      cannot.

    Algorithm:
        1. Choose the route for Σ̂_y from the shapes or ``dense_innovation``.
        2. Form the cross-covariance Σ̂_xy.
        3. Assemble Σ̂_y densely, or as a low-rank update of Σ_ε.
        4. Solve for the gain G = Σ̂_xy Σ̂_y⁻¹ row by row.

    Args:
        particles: Prior ensemble x⁽ᵉ⁾ in state space, one row per member.
        obs_particles: Its image h⁽ᵉ⁾ = h(x⁽ᵉ⁾) in observation space. A nonlinear h
            is linearised implicitly by the ensemble.
        obs_noise: Observation-error covariance Σ_ε.
        solver: Solver strategy for Σ̂_y; ``None`` uses structural dispatch. A
            matrix-free strategy wants ``dense_innovation=False``, so that it gets
            the structured operator.
        dense_innovation: Whether to form the (D_y, D_y) Σ̂_y densely. ``None``
            chooses by shape; ``True`` and ``False`` force the dense and the
            Woodbury route.

    Returns:
        The dense Kalman gain G. It is consumed once by the analysis and is usually
        small, since D_y counts the observations.

    Raises:
        ValueError: If the ensembles have different sizes, ``obs_noise`` is not
            (D_y, D_y), or N_ℰ < 2.

    Examples:
        Three members, with the first component observed:

        >>> import jax.numpy as jnp
        >>> import lineax as lx
        >>> import filterax
        >>> particles = jnp.array([[0.0, 0.0], [1.0, 1.0], [2.0, 0.0]])
        >>> obs_particles = particles[:, :1]
        >>> obs_noise = lx.DiagonalLinearOperator(0.5 * jnp.ones(1))
        >>> gain = filterax.kalman_gain(particles, obs_particles, obs_noise)
        >>> gain.shape
        (2, 1)
        >>> bool(jnp.allclose(gain, jnp.array([[2.0 / 3.0], [0.0]])))
        True

        The two routes agree to round-off:

        >>> woodbury = filterax.kalman_gain(
        ...     particles, obs_particles, obs_noise, dense_innovation=False
        ... )
        >>> bool(jnp.allclose(gain, woodbury, atol=1e-4))
        True

        One member has no sample covariance:

        >>> filterax.kalman_gain(
        ...     particles[:1], obs_particles[:1], obs_noise
        ... )  # doctest: +NORMALIZE_WHITESPACE
        Traceback (most recent call last):
        ...
        ValueError: Bessel correction requires J >= 2 particles (divisor is J - 1);
        got J=1. Pass bessel=False for a maximum-likelihood divisor.
    """
    # G = Σ̂_xy Σ̂_y⁻¹
    return gaussx.ensemble_kalman_gain(
        particles,

    obs_particles: Float[Array, "N_e N_y"],
    obs_noise: lx.AbstractLinearOperator,

        ValueError: If N_ℰ < 2, or ``obs_noise`` is not (D_y, D_y).

        >>> import filterax
        >>> obs_particles = jnp.array([[0.0], [1.0]])

        >>> covariance = filterax.innovation_covariance(obs_particles, obs_noise)

    def innovation_statistics(
    particles: Float[Array, "N_e N_x"],
    obs: Float[Array, " N_y"],
    obs_op: Callable[[Float[Array, " N_x"]], Float[Array, " N_y"]],
    obs_noise: lx.AbstractLinearOperator,
    *,
    solver: gaussx.AbstractSolverStrategy | None = None,
) -> InnovationStatistics:
    """Innovation diagnostics of a forecast ensemble.

        r̄ = y − h̄,   Σ̂_y = Σ̂_h + Σ_ε,   Σ̂_y^−½ r̄,   log 𝒩(r̄; 0, Σ̂_y)

    The whitened residual serves χ² and Desroziers-style consistency checks: under a
    correctly specified Σ̂_y each component is a unit-variance Gaussian. It uses the
    principal root through `gaussx.sqrt_inv_matmul`, a contour quadrature of shifted
    solves, so it does not depend on the order of the observations. With 30 nodes, its
    squared norm matches r̄ᵀ Σ̂_y⁻¹ r̄ to about 1e-10 (relative, float64) up to a
    condition number of 1e6.

    With N_ℰ ≤ D_y, the whitener goes through Woodbury and Σ̂_y is never materialised.
    Otherwise each Woodbury solve would factor the larger (N_ℰ, N_ℰ) capacitance, so
    Σ̂_y is formed densely. The log-likelihood comes from `ensemble_log_likelihood`.

    Algorithm:
        1. Map the members through h, and form r̄ and Σ̂_y.
        2. Choose the operator for the whitener from the shapes.
        3. Evaluate the log-likelihood.
        4. Whiten r̄ with 30 quadrature nodes.

    Args:
        particles: Forecast ensemble x⁽ᵉ⁾, one row per member.
        obs: Observation vector y.
        obs_op: Observation operator h on one state, mapped over the ensemble here.
        obs_noise: Observation-error covariance Σ_ε.
        solver: Solver strategy for the log-likelihood's log-determinant and solve.
            The whitened residual always uses structural dispatch.

    Returns:
        An `InnovationStatistics` mapping with ``innovation``, ``innovation_cov``,
        ``normalized_innovation`` and ``log_likelihood``.

    Raises:
        ValueError: If N_ℰ < 2.

    Examples:
        Two members, with the first component observed:

        >>> import jax.numpy as jnp
        >>> import lineax as lx
        >>> import filterax
        >>> particles = jnp.array([[0.0, 0.0], [1.0, 1.0]])
        >>> obs = jnp.array([0.5])
        >>> obs_noise = lx.DiagonalLinearOperator(jnp.ones(1))
        >>> stats = filterax.innovation_statistics(
        ...     particles, obs, lambda state: state[:1], obs_noise
        ... )
        >>> stats["innovation"].tolist()
        [0.0]
        >>> round(float(stats["log_likelihood"]), 4)
        -1.1217

        One member cannot supply a sample covariance:

        >>> filterax.innovation_statistics(
        ...     particles[:1], obs, lambda state: state[:1], obs_noise
        ... )  # doctest: +NORMALIZE_WHITESPACE
        Traceback (most recent call last):
        ...
        ValueError: particles must contain at least 2 ensemble members for the
        Bessel-corrected estimators to be well-defined; got N_e=1.
    """
    # ensemble_mean runs first, and einx cannot size an empty ensemble.
    check_ensemble_size(particles.shape[0])
    # h⁽ᵉ⁾ = h(x⁽ᵉ⁾)
    obs_particles = jax.vmap(obs_op)(particles)
    # h̄ = (1 / N_ℰ) ∑ₑ h⁽ᵉ⁾
    obs_mean = ensemble_mean(obs_particles)
    # r̄ = y − h̄
    residual = obs - obs_mean

    # Σ̂_y = Σ_ε + U Uᵀ
    obs_covariance = innovation_covariance(obs_particles, obs_noise)
    ensemble_size, obs_size = obs_particles.shape
    # At N_ℰ = 1000, D_y = 3 the 30 Woodbury solves below take 100 s against
    # milliseconds for the (D_y, D_y) matrix.
    solve_operator = obs_covariance
    if solver is None and ensemble_size > obs_size:
        dense_covariance = obs_covariance.as_matrix()
        solve_operator = lx.MatrixLinearOperator(
            dense_covariance, lx.positive_semidefinite_tag
        )
    # log 𝒩(r̄; 0, Σ̂_y)
    log_prob = ensemble_log_likelihood(
        obs_particles, residual, obs_noise, solver=solver
    )

    residual_column = einx.id("obs -> obs 1", residual)
    # Σ̂_y^−½ r̄. The default 15 nodes leave a relative error of 1e-5 in its squared
    # norm at a condition number of 6.5e6.
    whitened_column = gaussx.sqrt_inv_matmul(
        solve_operator,
        residual_column,
        num_quadrature=30,
    )
    whitened = einx.id("obs 1 -> obs", whitened_column)

    return InnovationStatistics(
        innovation=residual,
        innovation_cov=obs_covariance,
        normalized_innovation=whitened,
        log_likelihood=log_prob,
    )
